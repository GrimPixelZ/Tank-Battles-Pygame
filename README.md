# Tank Battles: Pygame Edition
A game project built to experiment with the capabilities of Pygame. Features:
- High-octane tank PvE gameplay
- Native controller support
- Local multiplayer
- An options menu

Acts as a successor to [Tank Battles: The Final War](https://scratch.mit.edu/projects/602182159/). Defold sequel coming soon...


# Installation
- Navigate to latest release
- Download executable for your OS
- Done :)
