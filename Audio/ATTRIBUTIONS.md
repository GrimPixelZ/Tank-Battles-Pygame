# Audio Credits & Attributions

The audio assets (sound effects and music) used in this game were sourced from public royalty-free repositories and public domain libraries, primarily believed to be Freesound.org. 

Because these assets were collected over a long development cycle, the specific filenames, creator names, and original URLs are currently untracked. 

### To the Creator Community:
We deeply respect intellectual property and the hard work of audio creators. If you are an artist or sound designer and you recognise your work in this game:
1. Please open an Issue in this repository or contact me at: grimpixz@gmail.com
2. Let me know which asset is yours and how you would like to be credited.
3. We will immediately update this file with your formal attribution, link, and license requirements.

### License Restrictions for Forks/Derivatives:
Because the original exact licenses (e.g., CC-BY, CC-BY-NC, or CC0) cannot be verified at this time, all audio assets in the `/Audio` directory should be treated as **Restricted / Non-Commercial Use Only**. They are **not** covered by the main repository's MIT code license.
